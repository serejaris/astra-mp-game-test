# Rift Brawl

Браузерная арена с видом сверху для 2–8 игроков. Открой игру и нажми **«Пригласить друга»**, чтобы скопировать ссылку на свою комнату. Пока ты один, с тобой играет тренировочный голем. С приходом второго игрока начинается трёхминутный матч. За каждый нокаут начисляется очко. При равном счёте объявляется ничья.

[Играть в Rift Brawl](https://riftbrawl.sereja.tech/)

## Управление

| Действие | Клавиши |
| --- | --- |
| Движение | WASD или стрелки |
| Прицел | Мышь |
| Арканный болт | Левая кнопка мыши, пробел или 1 |
| Сверхновая вокруг мага | Q или 2 |
| Скачок к прицелу | E или 3 |

На сенсорном экране двигайся левым пальцем и направляй огонь правым. Для сверхновой и скачка нажимай на соответствующие заклинания.

## Локальный запуск

Требуется Node.js 22 или новее.

```sh
npm ci
npm test
npm start
```

Игра слушает порт 3000. Переменная `PORT` задаёт другой порт. Сервер отдаёт клиент и принимает WebSocket-соединения на одном порту.

## Контейнер

```sh
docker build -t rift-brawl .
docker run --rm -p 3000:3000 rift-brawl
```

Для публичной установки HTTPS-прокси должен пропускать WebSocket на `/ws`. Проверка готовности — `GET /healthz`. Сервер рассчитывает движение, коллизии, урон и счёт. Комнаты работают в памяти процесса. После перезапуска приглашение откроет новый матч по прежнему адресу.

Арена, маг и иконки способностей созданы в ImageGen. Шрифты поставляются локально, их лицензии лежат в `public/assets/fonts`.
